# 星环突围 · ORBIT BREAKER

A free three-minute space survival arcade. Auto fire, eight upgrade paths, orbital drones, dashes and a final mothership.

WASD / arrows to move, Space to dash, Esc to pause. Touch controls are included. Beat the mothership before the three-minute deadline.

All graphics and sound are generated in the browser. No account, payment, ads or analytics. Scores stay in your browser.

This repository contains the published static game. Serve the root over HTTP(S) with JavaScript module support.

Version 1.0.0. No third-party runtime or asset dependencies.

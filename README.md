# 星环突围 · ORBIT BREAKER

Published version: 1.2.0.

A free three-minute space survival arcade. Auto fire, eight upgrades, dashes and a final mothership.

Desktop: WASD / arrows to move, Space to dash, Esc to pause. Pointer controls: drag to steer; flick after dragging or double-tap the arena to dash.

An unfinished run is saved locally. Use the continue button after reopening the game. Scores stay in your browser; no account, payment, ads or analytics.

Current runtime and source modules: `releases/1.2.0/`. The root HTML points to that immutable release path. Earlier runtime paths are retained so existing browser caches remain compatible.

Serve the repository root over HTTP(S). Artwork and sound are generated locally. Three.js is bundled with its MIT license.
